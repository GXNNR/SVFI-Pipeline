1. WHAT IT IS AND HOW IT WORKS
------------------------------------------------------------

SVFI Pipeline automates the whole round trip between
After Effects and SVFI.

Without the tool:
AE -> export -> open SVFI -> load video -> wait -> import -> align

With SVFI Pipeline:
Select layers -> "Render & Queue" -> keep working

The tool has 3 parts:

* Panel (Window > Extensions > SVFI Pipeline)
  The button, the queue and the settings.

* Background service (invisible, starts with After Effects)
  Runs SVFI one clip at a time, and imports each result.
  It keeps working even if the panel is closed.

* Launcher (File > Scripts > SVFI_Pipeline.jsx)
  Opens the panel. Can be called from other script
  launchers such as NyaUIPanel.

What happens when you press the button:

1. Each selected layer becomes a job in the queue.
2. AE renders the layers one after another, exactly as you
   see them in the comp. For that, the layer is soloed
   temporarily and only its in/out range is rendered.
   Your Solo switches, Work Area and Render Queue are
   restored afterwards.
3. When a render finishes, that clip goes to SVFI.
4. When SVFI finishes, the result is imported above the
   original layer, aligned in time, and the original layer
   is deleted (Ctrl+Z restores it).

AE does not freeze while rendering, and nothing touches
After Effects while it is rendering.

2. REQUIREMENTS
------------------------------------------------------------

[ ] Windows 10 or 11
[ ] After Effects 2019 (16.0) or newer
[ ] SVFI from Steam
[ ] steam_appid.txt file in the SVFI folder
[ ] Output module template "Clips RIFE" in After Effects

Python is NOT needed anymore.

IMPORTANT - steam_appid.txt:
SVFI needs this file to run from the command line.
Create it inside the SVFI folder, for example:
  D:\SteamLibrary\steamapps\common\SVFI\steam_appid.txt
With this exact content (nothing else):
  1692080

------------------------------------------------------------
3. INSTALLATION
------------------------------------------------------------

STEP 1 - Install SVFI
* Install SVFI from Steam and open it once.
* Create steam_appid.txt with the exact content: 1692080

STEP 2 - Create the "Clips RIFE" template in AE
* Edit > Templates > Output Module
* Duplicate an existing template
* Rename it to: Clips RIFE
* Format: QuickTime
* Codec: Animation or ProRes 422 HQ
* OK

STEP 3 - Install the extension
* Close After Effects completely.
* Run SVFI Pipeline\INSTALL_Windows.bat
* Windows asks for administrator permission once: it is
  only used to copy SVFI_Pipeline.jsx into the Scripts
  folder of every After Effects version found.
  If you say no, the panel still works from
  Window > Extensions.

STEP 4 - First run
* Open After Effects.
* Window > Extensions > SVFI Pipeline
  (or File > Scripts > SVFI_Pipeline.jsx)
* The dot at the top right must be green:
  "Service running".
* Open Settings and choose the work folder and the
  path to one_line_shot_args.exe (see section 4).

To uninstall: run UNINSTALL_Windows.bat

------------------------------------------------------------
4. SETTINGS
------------------------------------------------------------

Work folder
  Where the jobs are stored (renders, SVFI results, logs).
  Choose a folder on a disk with free space.

SVFI (one_line_shot_args.exe)
  Usually:
  D:\SteamLibrary\steamapps\common\SVFI\one_line_shot_args.exe

Preset .ini
  The SVFI settings used for every clip. By default it uses
  the preset included with the extension. See section 7 to
  use your own.

Output module template
  Name of the AE template used to render. Default: Clips RIFE

Delete the original layer after importing
  ON by default. If the original layer is a parent of other
  layers or a track matte, it is hidden instead of deleted.

Frame fix: repeated frames to remove
  Start (default 1) and End (default 7), counted in frames of
  the SVFI clip. Used by "Comp + fix frames".

Max SVFI time per clip
  If SVFI takes longer than this, the job is aborted.

Auto-import (switch in the main card)
  ON: each result is imported automatically, even with the
      panel closed.
  OFF: the job waits with an "Import" button.

Auto-comp (switch in the main card)
  ON: each imported clip is precomposed at its own frame rate
      (for example 191.808 fps), so every interpolated frame is
      kept and trims are exact.
      Comp only        Just the precomp, full clip.
      Comp + fix frames  SVFI leaves repeated frames at the start
                         and end of the clip. The precomp removes
                         them (1 at the start, 7 at the end by
                         default) and its duration is adjusted.
  OFF: the clip is imported directly, without a precomp.

------------------------------------------------------------
5. HOW TO USE IT
------------------------------------------------------------

STEP 1
Apply Time Remapping (or whatever you need) to the clip.
Trim the layer to the fragment you want: only the layer's
in/out range is rendered.

STEP 2
Select one or more layers in the timeline.

STEP 3
Click "Render & Queue selected layers".
Cameras, lights, nulls and hidden layers are skipped
(the panel tells you which ones).

STEP 4
Keep working. AE renders the layers one by one and then
returns to the comp. SVFI processes the queue in the
background.

STEP 5
With Auto-import ON, each clip replaces its layer when
SVFI finishes. The imported file is called <layer>_SVFI.mov
and goes into the "SVFI Results" folder of the project.
With Auto-comp ON, the layer is a precomp called <layer>_SVFI
(also in "SVFI Results") that contains the clip.

------------------------------------------------------------
6. THE QUEUE
------------------------------------------------------------

Job states:

Waiting AE   Waiting for its turn to render in AE
AE render    AE is rendering it
Queued       Rendered, waiting for SVFI
SVFI         SVFI is processing it (progress is shown)
Ready        Finished, waiting to be imported
Imported     Done
Error        Something failed (the reason is shown)
Cancelled    Cancelled by you

Buttons:

Cancel   Stops a waiting job or the SVFI process
Retry    Runs SVFI again for a failed job
Import   Imports a finished job (when Auto-import is OFF)
Remove   Removes a finished job from the list
Log      Opens the job's svfi_log.txt
Folder   Opens the work folder
Clean    Removes all finished jobs from the list and deletes
         their temporary files. Imported results are kept,
         because your project uses them.

7. CUSTOM SVFI PRESET
------------------------------------------------------------

1. Open SVFI
2. Configure the parameters you want
3. Start a test task with any video
4. Go to: SVFI\Configs\
5. Copy the most recent .ini file (several KB in size)
6. Save it somewhere outside the extension folder,
   for example: Documents\SVFIPipeline\my_preset.ini
7. Open it with Notepad and DELETE the line that
   starts with:
   gui_inputs=
8. Save
9. In the panel: Settings > Preset .ini > choose that file

You do not need to edit output_dir or the frame rates:
each job uses its own copy of the preset with its own
output folder and the comp's real frame rate, keeping
your preset's multiplier (for example x8).
Your preset file is never modified.

Do not edit the preset inside the extension folder:
reinstalling replaces it.

9. TROUBLESHOOTING
------------------------------------------------------------

PROBLEM: "Service not detected" (red dot)
SOLUTION:
* Restart After Effects.
* Check that this file exists:
  %APPDATA%\Adobe\CEP\extensions\com.gxnnr.svfipipeline\CSXS\manifest.xml
* Run INSTALL_Windows.bat again.

PROBLEM: The panel does not appear in Window > Extensions
SOLUTION:
* Run INSTALL_Windows.bat again (it enables unsigned
  extensions) and restart After Effects.

PROBLEM: "Output module template ... not found"
SOLUTION:
* Create the template (installation, step 2), or write
  the name of your template in Settings.

PROBLEM: A job ends in Error after SVFI
SOLUTION:
* Press "Log" and read the end of the file.
* Check steam_appid.txt and the SVFI path.
* Check that the preset has no gui_inputs= line.

PROBLEM: The original layer was not deleted
CAUSE: It is a parent of other layers or a track matte.
It is hidden instead, so nothing breaks.

PROBLEM: "After Effects error: Cannot run a script while
a modal dialog is waiting for response"
SOLUTION:
* SVFI Pipeline never talks to AE while it renders. If it
  appears, another panel is calling AE during the render.
  If you use NyaWatchTower, do not watch the SVFI_jobs
  folder.

Debug consoles (Chrome, with AE open):
  Panel:   http://localhost:8102
  Service: http://localhost:8103

10. UPDATING FROM VERSION 1.x
------------------------------------------------------------

* Version 2 replaces SVFI_Panel.jsx, svfi_orquestador.py,
  lanzar_svfi.vbs, Config.bat, Clean.bat and config.txt.
  You can delete the old "SVFI project" folder.
* Python and the folder permissions (icacls) are no longer
  needed.
* The last work folder used by the old panel is detected
  automatically.
